# 知乎 Morning Call 本地播放器

把「知乎 Morning Call」做成一个**本机网页**：一个大按钮，点开就播当天节目，顺带列出当天 10 条热点。

## 为什么需要它

知乎的 Morning Call 只能在其 App 里听，网页版没有播放入口；而且音频地址每天变、未发布时接口只给占位 id。

这个工具把整条链路搬到本地：

```
浏览器 ──▶ 本机 server.py ──▶ api.zhihu.com（取节目元数据 + m3u8）
                          ──▶ vdn3.vzuu.com（取音频分片）
```

浏览器全程只和 `127.0.0.1:8787` 通信，绕开跨域限制。

## 快速开始

双击 `start.cmd`（会自动开浏览器到 http://127.0.0.1:8787/），或者：

```bat
python server.py
```

依赖：Python 3.9+，**只用标准库**，无需 pip 安装。

> `vendor/hls.min.js` 已内置，离线可用。

## 界面

- 封面、标题、当日时长
- 76px 大播放按钮 + 进度条 + 时间
- 自动填充当天的音频直链（可手动换成别的 m3u8 / mp3）
- 当日 10 条热点，点击跳知乎
- 可选填知乎登录态 `z_c0`（未发布或需要登录时兜底）

## 自动播放说明

浏览器策略：没有用户交互时只允许**静音**自动播放。因此：

1. 打开页面即开始播放（可能是静音）；
2. 页面右下角出现 `🔊 点击开声`，点页面任意处即开声音；
3. 想让以后直接带声音，去 `chrome://settings/content/sound` 把 `127.0.0.1` 加为允许。

## 接口

| 路由 | 作用 |
|---|---|
| `GET /` | 播放页 |
| `GET /api/ep` | 代理知乎当日节目元数据（标题/封面/热点） |
| `GET /api/media` | 解析出可用 m3u8（带兜底 id、结果缓存到 `media_cache.json`） |
| `GET /hls?u=` | 代理 m3u8，并把分片改写成 `/seg?u=` |
| `GET /seg?u=` | 代理音频分片（二进制） |
| `GET /api/probe?u=` | 探测任意音频地址状态 |
| `GET /api/cookie?v=` | 保存知乎 `z_c0` |

所有响应带 `Cache-Control: no-store`，改完刷新即生效。

## 已知限制

- 音频地址由知乎服务端下发，**未发布时**会返回 `content not found: mcContentID=0`，页面会每 60 秒自动重试。
- 仅供本机个人使用；请遵守知乎的服务条款。
